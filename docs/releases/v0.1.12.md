# M45 Drive Watcher 0.1.12

- Start login sessions quietly in the tray using the default `--autostart` entry.
- Add **Open window at login** in Settings for users who want the overview at startup.
- Keep repeated login launches from raising an existing window.
- Use a separate Applications menu launcher that opens the overview on manual launch.

Validated with monitor, collector, Qt UI and preference tests, isolated desktop startup checks for both preference values, and Debian package construction.
