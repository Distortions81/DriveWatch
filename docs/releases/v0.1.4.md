M45 Drive Watcher replaces DriveWatch to avoid naming conflicts.

- New app, menu, notification, executable, package, collector, and desktop/D-Bus names.
- Existing baselines, settings, and login preferences are copied on first launch; original files are retained.

Quit the old DriveWatch tray process, then install and launch:

```sh
sudo apt install ./m45-drive-watcher_0.1.4_amd64.deb
m45-drive-watcher --show
```
