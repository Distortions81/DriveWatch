DriveWatch preview update for more tolerant SMART monitoring and a roomier drive overview.

- Increase the per-drive SMART timeout from 25 to 90 seconds.
- Report read-error alerts only after 30 minutes of consecutive failed checks. A successful read resets confirmation; actual health faults still alert immediately.
- Preserve read-failure confirmation across app restarts and show “Read pending” during confirmation.
- Increase the default overview window height and reserve more space for drive details, with a font-scaled minimum panel height and an adjustable divider.

The collector, monitor, and desktop UI test suites pass locally. The overview layout was also checked in a rendered preview.

### Install or upgrade

The package targets Ubuntu 24.04, amd64:

```sh
sudo apt install ./drivewatch_0.1.3_amd64.deb
```

Quit the existing DriveWatch process from its tray menu and reopen it after upgrading. Existing unread alerts remain in history until acknowledged.
