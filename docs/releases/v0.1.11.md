# M45 Drive Watcher 0.1.11

Summary now shows connection types such as Internal: NVMe, Internal: SATA, and External: USB, alongside negotiated connection speed. USB and PCIe link speeds come from the nearest device in sysfs; SATA uses its port speed or the current per-drive SMART interface speed. Unknown speeds remain unavailable. These are link rates, not throughput measurements. The overview remains compact.
