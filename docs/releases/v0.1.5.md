# M45 Drive Watcher 0.1.5

Choose which drives to monitor using the overview checkboxes. Choices persist across restarts; unchecked drives remain visible without alerts and are omitted from the tray popup. Turning monitoring off acknowledges that drive’s existing alerts while retaining history. Re-enabling starts a fresh baseline and still checks current health faults. Collection continues for all drives.

Names and serials now fall back to system metadata when SMART fails. The overview includes USB connection type, partition labels and mount locations, with external USB drives below internal drives. Confirmed unsupported SMART is shown separately from inaccessible SMART; neither is presented as healthy.
